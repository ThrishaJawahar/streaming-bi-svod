# 📊 Streaming Platform Strategy Analysis

## Project Overview
This project analyzes the content strategy of major streaming platforms using publicly available datasets, with a focus on understanding how Netflix positions itself in the competitive streaming industry.

---

## Objective
Identify strategic opportunities for a selected streaming platform (Netflix) using data-driven insights.

---

## Dataset
Movies and TV Shows on Streaming Platforms dataset.

The repository includes:
- Raw datasets (Data folder)
- Cleaned datasets used for analysis

---

## Methodology
- Data Cleaning (ETL preprocessing)
- Exploratory Data Analysis (EDA)
- Platform-Level Analysis (Netflix focus)
- SWOT Analysis
- Strategic Recommendation

---

## Key Findings
- Netflix focuses on high-volume, diverse content
- Content is dominated by movies and popular genres like drama and comedy
- Most content is recent (post-2015), indicating a modern content strategy
- There is an opportunity to expand niche and international content

---

## Repository Structure

- Data/ → Raw and cleaned datasets
- notebooks/ → ETL and EDA notebooks
- src/ → Utility functions
- README.md → Project documentation
- requirements.txt → Dependencies


---

## Tools Used
Python, Pandas, NumPy, Matplotlib, Google Colab

---

## Conclusion
Netflix’s strategy is centered around a large and diverse content library to attract a broad audience. However, there is an opportunity to strengthen differentiation by investing in niche, high-quality, and international content.
